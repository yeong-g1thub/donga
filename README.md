# Project Name
Achievement Tracker

## Features
- Allows the current state to be recorded.
- Allows you to check off essential goals.
- Identifies the optimal goals for achieving accomplishments based on the current situation.

## Getting Started
### Prerequisites
- Node.js 18+
- npm
### Installation
`
git clone https://github.com/yeong-g1thub/donga.git
cd donga.git
npm install
`
### Usage
`
npm start
`
## Testing
`
npm test
